# DevEnv Manager v1.8.0

This release includes the #116, #117, and #118 stabilization work.

## Highlights

- Hardened high-risk backend operations with plan -> token -> execute flows.
- Added stronger runtime/JDK/Python/port reliability checks.
- Added safer profile and Doctor repair execution.
- Added port resolution plan workflow.
- Added file association safety gates and app search.
- Refactored frontend into Fluent workbench shell.
- Added Command Palette.
- Added unified Risk UX.
- Added Light/Dark/System/High Contrast themes.
- Strengthened CI contract and frontend architecture checks.

## Installer

## Notes

- High-risk actions require preview, backup/receipt, confirmation token, execution result, and recovery guidance.
- Existing terminal/IDE sessions may need to be reopened after environment changes.

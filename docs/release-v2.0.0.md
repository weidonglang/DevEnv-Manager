# DevEnv Manager v2.0.0

v2.0.0 是一次基于 v1.7.0 稳定界面的完整能力重建。它保留原有导航、页面布局、控件和视觉习惯，将后续版本中已经验证有价值的能力重新接入，并删除面向用户的额外确认令牌步骤。

## 致歉与说明

我们向受 1.8.x 到 1.9.x 版本回归影响的用户致歉。前端重构期间曾出现页面大面积“不可用”、字段映射错误、按钮只有提示没有结果、深色和高对比模式难以阅读，以及旧功能入口丢失等问题。

这次没有继续修补不稳定的重构界面，而是回到 v1.7.0 基座逐项迁移能力。原始前端由哈希基线保护，新增功能放在独立适配层，并通过自动化契约和安全验收阻止接线回归。

## 主要更新

### 运行时与工具链

- 统一发现 JDK、Python、Node.js、Go、Maven、Gradle、Rust/rustup、.NET SDK 和其他开发工具。
- 区分 DevEnv 受管版本和外部安装；外部运行时不会被 DevEnv 直接切换或卸载。
- 受管安装完成后执行组件和版本强验证，不自动改变当前版本。
- 切换操作保存环境与指针回执，验证失败时自动恢复；可从历史回执再次恢复。
- Rust 支持稳定、测试和 nightly 工具链的安装、默认切换、更新和卸载。
- .NET SDK 通过 WinGet 管理 8/9/10 主版本，并保护机器上的最后一个 SDK。
- Git、SSH、npm/pnpm/yarn、pip/uv/Poetry、镜像源和本地数据库服务获得持久操作结果。

### 环境、项目与配置档案

- 同时展示进程环境和 Windows 用户环境中的 raw/expanded `JAVA_HOME`、PATH 与实际命令命中。
- 分拆重复、缺失、陈旧、Store Alias 和 PATH 过长等警告。
- 环境修复、PATH 清理和恢复在写入前备份，写入后回读并广播环境变化。
- 项目页真实使用 `root`、`projectTypes`、`detectedFiles`、`packageManager` 和 `recommendedRuntime` 数据。
- IDEA 检查、Java 消费端验证、项目端口和配置应用结果不再只显示短暂提示。
- 配置档案支持文件选择、预览、导入、复制、重命名、历史恢复和失败回滚。

### 端口、文件关联与清理

- 端口扫描具有超时和本机回退，避免 `netstat` 卡住整个页面。
- 每行展示可关闭性原因；PID 4、系统关键进程、服务所属和数据库进程不提供危险快捷结束。
- 明确识别的用户开发监听进程支持一次确认后直接释放，并验证端口是否已释放。
- 文件关联可按 `.txt`、`.md`、`.json` 等扩展名搜索，发现候选应用，预览修改并保存精确注册表备份。
- 清理页补齐磁盘概览、重复大文件、桌面与下载归档、Windows 回收站、软件占用和分区布局只读检查。
- 归档目标自动推荐非系统盘，也可使用系统目录选择器；移动计划由后端绑定、过期并单次消费。
- Windows 回收站执行后自动复扫；普通文件优先进入回收站，系统目录、用户文档、浏览器凭据和聊天数据继续受到保护。

### 交互、可靠性与验收

- 健康检查、计划创建、执行、导出和设置保存都有页面内持久结果，并自动聚焦到结果区域。
- 空白 toast 被抑制，不再写入无限增长的浏览器调试存储。
- 所有需要目录的输入优先使用系统选择器。
- 深色和高对比模式使用系统颜色回退，长路径和错误文本可安全换行。
- PowerShell 统一经过有界 runner，支持超时、输出限额、编码识别和进程树终止。
- 新增 Static、Safe、Frontend、Report 四层验收；CI 检查后端/UI 漂移、数据字段、动作接线、稳定 selector、toast-only 和质量回归。

## 升级与兼容

- 保留 Tauri identifier `com.weidonglang.dailytools`，沿用既有安装和配置位置。
- 可从旧版直接安装升级；重要环境变量、项目配置和 Profile 操作前仍建议备份。
- 2.0.0 不会自动接管外部 JDK、Python、Node、Go、Rust 或 .NET 安装。
- 已打开的终端、IDE、服务和守护进程可能需要重启才能读取新的用户环境。
